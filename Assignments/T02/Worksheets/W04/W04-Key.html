part 5Why Copy Constructors Matter — Q8

Shallow-copying a pointer duplicates the address, not the memory it points to. Two objects end up owning the same heap block; when either is destroyed (or reassigned/freed), the other is left with a dangling pointer, and if both eventually free the block, that's a double free. Modifying data through one object also silently affects the other.

part 10Write the Class — Book (model answer)
class Book {
    string title;
    string author;
    int pages;
public:
    Book()
      : title("Unknown"), author("Unknown"), pages(0) {}
    Book(string t, string a)
      : title(t), author(a), pages(0) {}
    Book(string t, string a, int p)
      : title(t), author(a), pages(p) {}
    Book(const Book& other)
      : title(other.title), author(other.author), pages(other.pages) {}
};
