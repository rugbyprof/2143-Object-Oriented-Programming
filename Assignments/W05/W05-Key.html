part 3Constructor Chaining — Q4, Q5

Q4: Prints A B C — construction always runs base-first, all the way down the chain, before the most-derived constructor body finishes. Destructors run in the exact opposite order: ~C ~B ~A.

part 4Overriding vs. Overloading — Q6, Q7

Q6: v.describe(); prints "A vehicle." — c.describe(); prints "A car.". To call the base version from inside the override: Vehicle::describe();

  1. Car(string) / Car(string,int) — OVERLOADED (same name, different parameter lists, same class)
  2. Vehicle::describe() / Car::describe() — OVERRIDDEN (identical signature, redefined in the derived class)
  3. Vehicle::describe() / Car::honk() — NEITHER (different names — unrelated functions)
  4. operator+(Fraction) / operator+(int) — OVERLOADED

part 5Hierarchical Inheritance — Q8 (model answer)
class Motorcycle : public Vehicle {
    bool hasSidecar;
public:
    Motorcycle(string mk, string mo, int spd, bool sidecar)
        : Vehicle(mk, mo, spd), hasSidecar(sidecar) {}

    void describe() {
        Vehicle::describe();
        cout << (hasSidecar ? "Has a sidecar.\n" : "No sidecar.\n");
    }
};
part 6Find the Error — Case A, B, C
Case A class Car : Vehicle with no keyword defaults to private inheritance (mirrors W01: no label = private). That turns every inherited public member of Vehicle, including describe(), into a private member of Car. Line X (c.describe(); in main()) does NOT compile — describe is private within this context. Fix: class Car : public Vehicle.
Case B Does NOT compile. Car(int doors) never chains to a Vehicle constructor, so the compiler tries to call Vehicle() implicitly — but Vehicle only has Vehicle(string mk), no default constructor. Missing: a way to supply mk. Fix: give Car a string parameter too and chain it — Car(string mk, int doors) : Vehicle(mk), numDoors(doors) {}.
Case C Does NOT compile. protected only widens access for derived classes — it does nothing for outside code. main() is not a member of Vehicle or any class derived from it, so v.make is just as unreachable as if make were private.
