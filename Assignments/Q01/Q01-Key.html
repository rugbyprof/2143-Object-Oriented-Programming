Two class definitions, data members only. Access specifiers are not required by the prompt, but private: members are the expected default and should be rewarded.

// Stack — array-based
class Stack {
private:
    int *array;     // heap-allocated element buffer
    int  capacity;  // number of slots in array
    int  top;       // index of the most recent push; -1 when empty
};
// Queue — singly linked list
class Queue {
private:
    Node *front;   // dequeue from here (head)
    Node *rear;    // enqueue here (tail)
};
Grading notes

What counts

Stack — min
int *array; + int top;. Full credit also for a capacity / size member; templated element type is fine.
Stack — watch
Missing the * on array; int array[]; with no size (not a valid non-static member); using front/rear names.
Queue — min
Node *front; + Node *rear;. A Node definition is not required; an extra int count; is acceptable.
Queue — watch
Only one pointer (no O(1) enqueue without rear); calling the members top/array; pointer type written as the value type (Node front;).
Auto-deductions
Any method (push, pop, enqueue, dequeue), constructor, or destructor — these were explicitly excluded.
Cosmetic
Node *front vs Node* front — spacing does not matter. Trailing semicolon after } required for the class to compile.
If Node shown
Should carry int data; and Node *next;.
